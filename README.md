# Tic Tac Toe (Крестики-нолики) 🎮

Классическая игра "Крестики-нолики" на Java с консольным интерфейсом.

## 📋 Описание

Двухигрокская консольная игра, где два игрока по очереди ставят свои знаки на поле 3×3. Первый, собравший 3 своих знака в ряд — побеждает.

## 🎮 Управление

- Введите номер клетки **1–9** для хода (числа расположены сверху вниз, слева направо)
- Введите **`s`** — сделать случайный ход (для тестов)
- Введите **`h`** — показать правила
- Введите **`q`** — выйти из игры

## 🧩 Правила

1. Двое игроков: Игрок 1 играет за **X**, Игрок 2 — за **O**.
2. Игроки ходят по очереди.
3. Победитель — первый, собравший 3 своих знака в ряд (горизонтально, вертикально или диагонально).
4. Если все клетки заняты и победителя нет — игра заканчивается в ничью.

## 🚀 Запуск

```bash
javac TicTacToe.java
java TicTacToe
```
